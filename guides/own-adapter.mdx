Sanning has an adapter for LangChain and LangGraph, in Python and TypeScript. A guide
to building your own adapter, for any other framework or for your own code, is not
available yet.

An adapter records every step of a run from one place in your code. So nothing depends
on a call that someone remembers to add to each step.
