This page sets up what your agent needs to record for production: a Live API key, a seed for its signing key, and the SDK. It takes about five minutes. You need Node.js 22 or later, or Python 3.11 or later.

<Note>
  To test first, use a Sandbox API key. It records the same way, but nothing it records is evidence. See [Test in the Sandbox](/sandbox).
</Note>

## Make a Live API key

An API key proves to Sanning which organization your agent records for. It never signs a record.

1. Sign in to `console.sanning.io`. If a strip across the top says Sandbox, select **Switch to live**.
2. Open **Settings**, then **API keys**, and select **Create key**. Only an owner or admin can create one.
3. Name the key and leave **Verify** unchecked. A key without Verify can record and read.
4. Copy the key. The console shows it once.

A Live API key starts with `sanning_prod_`.

## Make a seed for the signing key

Your agent signs every record with its signing key, an Ed25519 key. You make the key from a 32-byte seed. You make the seed once, you keep it, and Sanning never receives it.

<CodeGroup>

```bash OpenSSL
openssl rand -hex 32
```

```bash Python
python -c "import secrets; print(secrets.token_hex(32))"
```

```bash Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

</CodeGroup>

Keep the same seed for the life of the agent. A different seed is a different agent. Sanning enrolls the signing key on your agent's first record, so you do not register it anywhere.

## Store both as environment variables

Put the seed and the API key in the secret store that your service already uses. The adapter guides read them from `SANNING_SIGNING_SEED` and `SANNING_API_KEY`. To follow along from a terminal, export both:

```bash
export SANNING_SIGNING_SEED=SEED
export SANNING_API_KEY=API_KEY
```

Replace the following:

- `SEED` with the 64 hex characters that you made.
- `API_KEY` with the Live API key that you copied.

Never commit either value to your code.

## Install the SDK

<CodeGroup>

```bash TypeScript
npm install @sanning/anchor
```

```bash Python
pip install sanning-anchor
```

</CodeGroup>

An adapter is a separate package. Each adapter guide shows how to install its own.
