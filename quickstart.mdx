This page gets you ready to record an agent. You make two secrets, install the SDK,
and then choose how to record. It takes about five minutes.

## Before you start

You need:

- Python 3.11 or later, or Node.js 22 or later.
- An organization on `console.sanning.io`. Sanning is in early access, so there is no
  sign-up form. [Contact the team](mailto:TODO-ACCESS-LINK) for an API key.

## Get an API key

1. Sign in to `console.sanning.io`.
2. Open **Settings, API keys** and select **Create key**. Only an owner or admin can
   create one.
3. Name the key, and leave **Verify** unchecked. The key can anchor records and build
   evidence packs.
4. Copy the key. The console shows it once.

The API key authenticates your organization to Sanning. It never signs a record. For
the two kinds of API key and what each one can do, see
[API keys and signing keys](/reference/api-keys).

<Note>
  **To test first, use the Sandbox.** In the console, open the account menu and select
  **Switch to sandbox**, then make an API key in the same way. Your code does not
  change: the SDK reads the API key and marks every record Sandbox. A Sandbox evidence
  pack verifies, but it says Sandbox and is not evidence. See
  [Sandbox and Live](/reference/api-keys#sandbox-and-live).
</Note>

## Make a signing seed

Your agent signs its records with an Ed25519 key. You make its 32-byte seed once, and
keep it. Sanning never receives it.

<CodeGroup>

```bash OpenSSL
openssl rand -hex 32
```

```bash Python
python -c "import secrets; print(secrets.token_hex(32))"
```

```bash Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

</CodeGroup>

Keep the same seed for the life of the agent. A new seed on a later run reads as a
change of identity that nobody authorized, and the check fails.

Store the seed as `SANNING_SIGNING_SEED` and the API key as `SANNING_API_KEY`, in the
secret store that your service already uses. To follow the guides from a terminal,
export both:

```bash
export SANNING_SIGNING_SEED=SEED
export SANNING_API_KEY=API_KEY
```

Replace the following:

- `SEED` with the 64 hex characters that you made.
- `API_KEY` with the API key that you copied.

Sanning enrolls the seed's public key on your agent's first record. There is no
separate registration step: the agent then shows on the **Agents** page of the
console.

## Install the SDK

<CodeGroup>

```bash Python
pip install sanning-anchor
```

```bash TypeScript
npm install @sanning/anchor
```

</CodeGroup>
