Each term has one meaning on this site, and the docs use no other word for it. Code
names such as `event_id` and `eventType` keep their spelling.

## Terms

| Term | Meaning |
|---|---|
| Adapter | Code inside an agent's process that turns a framework's callbacks into records. The SDK signs and sends them. |
| Agent | The signing party. Its identity is its signing key, not its name. |
| Anchor | To sign a record and send the signed envelope to Sanning. The first verb of the lifecycle: anchor, read, verify. |
| API key | The credential for your organization. It authorizes calls and never signs evidence. Its prefix decides Sandbox or Live. |
| Case | A set of records, named by `context.case_id`, that belong to one piece of work across agents. |
| Closing record | The `agent.run_closed` record. It lists the records of its invocation and states how the invocation ended. |
| Content | The bytes a record commits to. The agent keeps them in its log store. Sanning does not receive them. |
| Content-blind | Sanning does not receive the content an agent produced. It holds in Private mode, the only mode offered at launch. Sanning holds a salted hash of each record (`payload_hash`). |
| Control plane | The Sanning service for issuance, enrollment, metering and billing. It is not in the trust path. |
| Envelope | The signed wrapper around a record. It carries the signature and the hash the signature covers. |
| Event type | The name of a record's kind, such as `agent.tool_call.started`. See [Event types](/reference/event-types). |
| Hand-off | A message from one agent to another. Each side signs its own record: `agent.handoff.sent` and `agent.handoff.received`. |
| Hash-only field | A field a record commits to through `event.content_hash` and does not show. You can reveal it. |
| Hidden field | A clear field a record withholds. The record keeps the hash of its value in `context.hidden`. |
| Id | An opaque identifier of 1 to 128 characters. Never hashed, and sent to Sanning in clear. Never a name, a path or customer content. |
| Invocation | One run of an agent from its input to its output. Its id is `run.root_run_id`. |
| Kernel | The open-source code that verifies a pack offline: `sanning-proof` in Python, `@sanning/proof` in TypeScript. |
| Live | The mode whose stamps reach the public record. Its API keys start `sanning_prod_`. |
| Log store | The storage you keep, where the SDK writes content and canonical records before it anchors. |
| Nonconforming | The reason kind of a `failed` verdict when the only disproven claim is `follows_rules`: a record is signed and intact and breaks the vocabulary it names. Shown as "Failed: a record does not follow the rules." The command line exits 1. Nothing is proven altered. |
| Operation | One unit of work inside an invocation, such as a step, a model call or a tool call. It is a `started` record and an `ended` record. |
| Pack | One zip of `bundle.json` and a `logs/` folder, which a third party verifies offline. |
| Record | What an agent signs for one moment: a `sanning.events/v2` record with one of the 19 `agent.*` types, or one of the seven types outside the agent vocabulary: `event`, `checkpoint`, `declaration`, and the four runner types `runner.run_opened`, `runner.run_closed`, `runner.egress` and `runner.relay`. |
| Refused record | A record the SDK would not sign because it breaks the schema or the type rules. Nothing is sent. `recordingStatus().refused` lists it by event id, type, reason and pointer. |
| Revealed field | A hash-only field carried in clear. Its path is listed in `context.revealed`. |
| Salt | A random 128-bit value the SDK writes into every record, as `context.salt`. It stops anyone who holds only the envelope from confirming a guessed short value against its hash. Sanning does not receive it. |
| Sandbox | The mode with simulated stamps. Its API keys start `sanning_test_`, and its packs verify as Sandbox. |
| Scrub | Replacing the value of a credential-shaped key with `"[scrubbed]"` before hashing. Declared in `context.content_scrubbed`. |
| SDK | The package that signs and sends records: `@sanning/anchor` or `sanning-anchor`. |
| Signing seed | The 32 bytes your agent's Ed25519 signing key comes from. Sanning never receives it. |
| Stamp | The signed commitment that a set of records existed by a time. Sanning stamps on an interval. |
| Trust path | What a verifier must believe for a verdict to hold. Sanning is never in it. |
| Verifier | Anyone who checks a pack or a record on their own machine, with no account and no call to Sanning. |

For what a verified record proves, see [What a pack proves](/concepts/what-a-pack-proves).
